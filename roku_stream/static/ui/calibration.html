Get back to 720p60

      
  1. Restore the capture connection first. If USB is detected but the capture driver is missing, power the Hauppauge off, disconnect and reconnect its USB, then power it on. Wait for “Capture device available.”
    2. 
        
  2. Check the component signal. If the capture device is available but there is no signal, check the converter’s power and the component cables into the Hauppauge.
    3. 
        
  3. Run the resolution change. Press the physical resolution button, start the watch above, and let the full cycle finish before pressing again.
    4. 
        
  4. Confirm the incoming format. Wait for stable 1280 × 720, progressive, 59.94 or 60 fps. Master’s output resolution does not establish the Hauppauge’s input resolution.
