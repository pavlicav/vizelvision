Viewer Roku · cable return

Checks Roku playback and compares the cable picture with the VizelVision master every few hours. Each comparison samples about 30 seconds to allow for playback delay. A missing or stopped app gets one launch attempt. TV-Thing locks are always respected; a locked or busy check waits 15 minutes.

Details

Check now uses saved settings and can relaunch VizelVision; it works while periodic checks are off. An active cable tuner on another channel is left alone. Launch sends only a Roku launch to the saved IP and app ID; it skips TV-Thing, so it works while TV-Thing is locked.
